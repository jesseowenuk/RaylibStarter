# Raylib Starter
A project so I don't have to start from scratch each time I want to use Raylib on my mac.

To use clone repository

```
git clone https://github.com/jesseowenuk/RaylibStarter.git
```

Then in the root directory run

```
cmake -S . -B build
cmake --build buld
./build RaylibStarter
```

Note: Of course change the project name to whatever you call it.
